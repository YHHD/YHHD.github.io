AI 内容流水线，真正难的是把人工审核留在正确的位置

douyin-matrix 是一条面向 AI 工具图文账号的内容流水线。它把重复劳动拆成固定阶段，但默认把“最终发布”留给人工。

整体链路是：

数据源
  → 国内可访问性过滤
  → 生成多种风格文案
  → Puppeteer 渲染多套视觉模板
  → 推送到飞书多维表格
  → 人工审核并发布

每一段只负责一种判断

抓取层只回答“最近有什么工具值得看”；过滤器只标注它是否需要特殊网络环境；生成层产出三种语气版本；渲染层把文案转成七张固定结构的长图；飞书负责让人看到结果并确认状态。

这种拆法比“一个 Agent 从头做到尾”更容易排查，也更适合失败后局部重跑。

七张图其实是一条内容结构

账号矩阵使用固定的七页模板：

  1. 封面：工具名和一句话钩子；
  2. 是什么：核心功能；
  3. 使用场景：三个具体例子；
  4. 怎么用：快速上手三步；
  5. 优缺点：优势和局限同时出现；
  6. 价格：费用与国内可用性；
  7. 尾页：关注引导和互动问题。

模板固定的好处是生产稳定，代价是内容容易同质化。解决方式不应该只是换颜色，而是让每一期都至少有一个真实测试结果、一个适用边界或一个反例。

自动化应该停在哪

这个项目没有把“自动发布”当作终点。模型可以生成草稿、排版和候选标题，但事实核验、工具的真实可用性以及账号语气，仍然需要人在发布前做最后判断。

自动化的价值不是把人从链路里删掉，而是把人从复制、排版、上传和状态同步里解放出来，把注意力留给内容中真正需要判断的部分。
